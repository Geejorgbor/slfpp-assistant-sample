## How Lucas opens them

1. Open Finder/Files (or any file browser) and go to `/workspace/slfpp-sample/`.
2. Double-click **`index.html`** to open the demo in a browser (`file://` is enough — no server required).
3. Use **`proposal.html`** for a print-ready pitch (browser → Print / Save as PDF if needed).
4. From the demo footer or proposal CTA, jump between the two pages.

On the shared box, you can also run:

```bash
xdg-open /workspace/slfpp-sample/index.html
# or
xdg-open /workspace/slfpp-sample/proposal.html
```
